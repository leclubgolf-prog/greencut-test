Créer une table

Vous êtes l’hôte : la partie tourne sur votre appareil. Gardez cette page ouverte jusqu’à la fin.

Les places libres sont tenues par des joueurs simulés. Un joueur qui ne répond pas pendant 60 secondes est couché automatiquement.

Rejoindre une table

Entrez le code que l’hôte vous a communiqué.

La partie démarrera dès que l’hôte la lance : cette page s’ouvrira toute seule sur la table.

Version de test : pseudos et parties de démonstration uniquement, aucune donnée client. La table ne garde rien après la partie.
