# Greencut – version de test mobile (autonome)

Pages HTML ordinaires, sans dépendance à l'outil de maquette. Point d'entrée : `index.html`
(ouvre la version verticale ou horizontale selon l'orientation du téléphone).

Pages : OuvertureMobile, ConnexionMobile, TableMobile, ParcoursMobile (+ versions `Paysage`).
Moteur de jeu : `shared/engine.js` ; style : `ds/greencut/` ; affichage : `support.js`.

Publication : GitHub Pages (Settings → Pages → Deploy from a branch → main / root).
Ajout à l'écran d'accueil iPhone : Safari → Partager → « Sur l'écran d'accueil » → plein écran.
Prototype de test : la partie n'est pas enregistrée, rien n'est envoyé à LeClub Golf.
